ТРЕНАЖЁР МОДО — ЗАПУСК БЕЗ УСТАНОВКИ PYTHON

1. Распакуйте ZIP на компьютере.
2. Зайдите на https://github.com и зарегистрируйтесь/войдите.
3. Создайте новый репозиторий (New repository), например modo-matematika-4. Можно выбрать Private.
4. Выберите Add file -> Upload files. Загрузите СОДЕРЖИМОЕ папки modo_ai_project (app.py, requirements.txt, questions.json, render.yaml, .gitignore, README.md, папку templates). Важно: app.py и render.yaml должны быть в корне репозитория, а templates/index.html внутри папки templates.
5. Нажмите Commit changes.
6. Откройте https://dashboard.render.com -> New -> Blueprint. Подключите GitHub, выберите созданный репозиторий и подтвердите создание сервиса из render.yaml.
7. При запросе OPENAI_API_KEY укажите действующий ключ OpenAI API в панели Render (Environment). НЕ записывайте его в GitHub или в HTML. Без ключа будет работать встроенный банк вопросов в случайном порядке, а не генерация ИИ.
8. Дождитесь статуса Live. Откройте HTTPS-ссылку вида https://modo-matematika-4.onrender.com (фактический адрес покажет Render).
9. Пройдите тест и проверьте почту charming_nastena@mail.ru. Если письмо не пришло, проверьте EmailJS Email History, шаблон и разрешения сервиса.
10. Откройте эту же ссылку на iPhone через Safari. Нельзя использовать локальный путь file:/// или C:\\...

ВАЖНО
- У Render могут меняться доступность бесплатного тарифа и интерфейс регистрации.
- EmailJS уже настроен на отправку на charming_nastena@mail.ru. В шаблоне можно добавить {{details}} для полного разбора.
- Если в EmailJS включён список разрешённых доменов, добавьте адрес вашего Render-сайта.
- Сгенерированные ИИ математические задания могут содержать ошибки: перед использованием с детьми проверьте несколько тестов.
- Текущая версия хранит активные попытки в памяти сервера. При перезапуске сервера незавершённые тесты потеряются. Не используйте для официального оценивания без доработки хранения и проверки заданий.
- Имя и класс ученика передаются через EmailJS: учитывайте требования школы к обработке персональных данных детей.
