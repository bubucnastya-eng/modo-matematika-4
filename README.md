# МОДО: ИИ-тестирование, 4 класс

## Запуск на компьютере
1. Установите Python 3.10+.
2. В папке проекта выполните `pip install -r requirements.txt`.
3. Задайте переменные окружения из `.env.example` (сам файл .env.example автоматически НЕ загружается).
4. Выполните `python app.py`, откройте `http://127.0.0.1:5000`.

## ИИ
Укажите действующий OPENAI_API_KEY. При каждом обновлении страницы сервер запрашивает новый вариант из 30 заданий. Если ключ не указан или ИИ недоступен, используются исходные 30 вопросов с перемешиванием вариантов. Источник отображается на странице. Ответы ИИ могут содержать ошибки: проверьте качество заданий перед использованием для оценивания.

## iPhone / Android
Нужно разместить Flask-приложение на HTTPS-хостинге (например, Render с командой запуска `gunicorn app:app`), добавить переменные окружения в настройках сервиса и отправить ученикам публичную HTTPS-ссылку. Открытие локального HTML-файла или Jupyter-файла с телефона не запускает сервер. На бесплатном тарифе некоторые хостинги засыпают.

## Важное перед массовым использованием
Пример рассчитан на пилотное тестирование. Для реального класса следует добавить хранение попыток и ответов в базе данных (сейчас временная память процесса), ограничение запросов к ИИ, защиту от повторной отправки, проверку ИИ-заданий учителем, политику обработки данных учеников и HTTPS. На многопроцессном хостинге используйте один worker либо замените QUIZZES на Redis/БД. Не помещайте API/SMTP-ключи в HTML, ноутбук или репозиторий. Не загружайте .env с секретами в публичный GitHub.
